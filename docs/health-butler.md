# DiskPilot 定位升级：从「磁盘清理工具」到「整机健康管家」

> 状态：方案（2026-10-01）· 读者：产品/开发 · 目的：把已有的 AI 代理、75 个 MCP 工具、
> 传感器/风扇写控、清理脚本体系串成一条**「预检 → 清单 → 一键确认」的自动化维护流程**，
> 给产品定位和分期排期定方向。所有条目都挂在真实代码上，不是概念稿。

## 1. 一句话定位

**磁盘清理是入口，整机健康是目的地。**
用户不再需要「想起来了才手动清一次」——DiskPilot 像管家一样定期体检、主动报忧、给出清单，
动手前永远等用户点头（安全铁律不放松），清完自动记账、下次接着管。

## 2. 现状资产盘点（已就绪，按管家场景归位）

| 管家能力 | 已有实现 | 代码位置 |
|---|---|---|

**缺口只剩「串起来」**：各能力目前是散点（总览、清理页、工具页、优化页、AI 对话各管一段），
没有一个"管家视角"把它们编排成有节奏的例行维护。

## 3. 体验蓝图：预检 → 清单 → 一键确认

一条固定的三步节奏，贯穿所有会动盘的功能（清理、优化、风扇）：

```
预检（只读，秒级）
  ├─ 盘还剩多少 / 哪些 scaffold 涨了（对比上次建议快照）
  ├─ 前置条件齐不齐（应用要退、文件被占用、需要管理员…）
  └─ 风险标注（保留期未到 / 疑似个人文件 / 多账号覆盖）
        ↓
清单（只读，出数不删）
  ├─ 按 scaffold 分组：预计可回收多少、为什么能回收
  ├─ 默认勾选 = 预检推荐（用户可逐项取消）
  └─ 单位与口径统一写「约 / 预计」，不伪装精确
        ↓
一键确认（唯一的写操作闸门）
  ├─ 第一次点 = 预备态（5s 倒计时，可反悔）
  ├─ 第二次点 = 执行 → 进系统回收站（非永久删）
  └─ 结果三态：成功 N 项 / 部分失败 M 项 / 一条没匹配到
        ↓
记账（自动）
  ├─ 操作历史台账 + 已释放空间累计
  └─ 空间趋势曲线、下次预检的对比基线
```

这套节奏**已经全部存在**——`cleanup_preflight` 就是预检，`cleanup_suggestions` 就是清单，
两步确认就是闸门，历史页就是记账。要做的是把它从「清理页专属」提升为**全应用统一范式**：
风扇写控、电源计划切换、启动项禁用都按同一个三步走（风扇已做到 L2 每次确认，可作样板）。

## 4. 分期路线

### P0 — 管家首屏（把散点编排成一页）
- 总览顶部加「今日体检」条：一条横幅汇总（红盘告警 / 可回收合计 / 温度是否异常 / 启动项变化），
  每项可点进对应流程。红盘救援横幅（≥85%）已验证过这个交互，横向扩即可。
- 「建议清理」卡与「分类占用」卡已同源对齐（按选中盘），补**跨次对比**：
  "比上次多出 X GB" —— 用 `cleanup_suggestions` 快照 diff，纯前端。
- 清理提醒（已有）升级成**管家通知**：文案从「可清理空间超阈值」扩到
  「温度持续偏高 / C 盘三周没扫 / 启动项悄悄加了两个」。

### P1 — 例行巡检（让管家有节奏）
- 周巡检任务：一次只读打包体检（扫盘 + 建议 + 硬件快照 + 温度均值），结果进历史台账，
  出一张「本周健康简报」。复用现有 `cleanup_reminder` 的调度与通知管道，不新建机制。
- 简报里的每一条都可下钻到既有清单/确认窗——**巡检本身永远只读**。
- AI 入口：对话里说「帮我看看这周怎么样」→ agent 依次调只读 MCP 工具（`disk_usage` /
  `hw_report` / `sensor_*` / `cleanup_suggestions`）汇总作答。工具已在，缺的是这段编排提示词。

### P2 — 主动干预（谨慎，逐项过安全评审）
- 允许用户**按项授权**：「以后微信缓存超 5GB 自动进清单」仍是出清单，只是免去「想起来要看」；
  任何自动**删除**依旧不做（铁律）。
- 风扇曲线托管：温度持续 > 阈值时提示应用一条预设风扇曲线（写操作，L2 每次确认不变）。
- 插件市场接入社区体检包（scaffold 之外的检查项），索引仓库上线后按契约分发。

### 明确不做（红线）
- ❌ 任何「静默自动删除」——先清单 + 用户确认，永久不变。
- ❌ 绕过回收站的永久删作为默认路径。
- ❌ macOS 签名公证（太贵）：社区自行构建，官方二进制只发 Windows/Linux。
- ❌ 为管家化引入新的高权限常驻服务——现有普通权限 + 按需提权（runas）模型不变。

## 5. 与竞品的差异化（对照 MangoDisk 调研）

| 维度 | MangoDisk | DiskPilot 现状 | 管家化后 |
|---|---|---|---|
| 清理本业 | 强（UI/运营）| 中（脚本体系扎实、UI 在改版）| 预检+清单+记账的确定性流程 |
| 体积 | 9.5MB | 偏大（插件化按需下载是主攻方向）| 同左 |
| AI 代理 | ❌ | ✅ 75 MCP 工具可被任意 agent 调 | **管家大脑，独有** |
| 硬件读写控 | ❌ | ✅ 温度读 + 风扇写控 + 熔断 | **管家手，独有** |
| 主动巡检 | 手动触发 | 提醒已有、周简报待做 | **管家的节奏感** |

一句话：竞品是「更好用的清理器」，管家化后的 DiskPilot 是「会体检、会报账、动手必问的维护代理」——
清理只是它最常用的一项服务。

## 6. 验收口径（每个 P 档的门禁）

- 安全：任何写路径都必须能在操作历史里查到，且默认进回收站；自动化的只有**只读体检**。
- 性能：管家首屏新增数据全部来自缓存/历史文件，**不为展示新造全盘 walk**（低配红线）。
- 一致性：预检、清单、通知的口径共用 `cleanup_suggestions` 单一数据源，杜绝两处数字打架。
- 回归：`pnpm -C apps/desktop check` + `cargo test --workspace` 全绿；新增纯逻辑必须配单测。
