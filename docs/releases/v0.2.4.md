# DiskPilot v0.2.4 更新日志（2026-11-02）

面向用户的发布说明（GitHub Release 描述可直接粘贴本文件）。
详细逐轮记录见 [CHANGELOG.md](../../CHANGELOG.md) 的 `[0.2.4]` 段（R485–R499）。

## 亮点

- **社区清理脚本闭环**：Studio → 清理脚本 → 社区脚本仓库现在可以一键「刷新索引」，
  从官方社区索引拉取最新清理脚本并一键安装。安装全程强制 Ed25519 签名 + sha256 +
  红线校验，不合格脚本不会落盘。作者侧可用 `scaffold-lint sign` 给自己的脚本签名后
  提交上架（详见 [docs/scaffold-authoring.md](../scaffold-authoring.md) §5）。
- **键盘可访问性专项**：Steam 游戏盘点列表、工具墙卡片、Treemap 空间图块全部支持纯键盘操作
  （方向键移动、Enter / Shift+Enter 激活，roving tabindex 不再让 Tab 停靠几十次）。
- **快捷键帮助面板**：任何页面按 `?` 即可唤出全局快捷键速查表（Esc 关闭）。

## 新功能与改进

- 社区脚本仓库支持远程刷新官方索引（R497），来源、更新时间与签名状态一目了然
- 观测总览 MCP 只读工具 `observations_overview`（R485）：一眼看尽本机被观测成什么样
- 健康周报增强（R486）：扫描趋势环比 + 观测层异常告警，巡检从单次快照升级为带趋势/异常的洞察

## 修复与工程化

- 修复 main CI 三个根因：unix 编译门控、node20 无 navigator、cargo audit 15 个漏洞全部清零（R488）
- unix clippy `-D warnings` 清零（R489）；补齐工具数断言残留（R490）
- 例行依赖更新：Rust 侧 113 包升到兼容范围最新、构建链精确锁回（R495）；
  前端 10 包升到声明范围内最新、Tauri 2.x 与 Rust 侧版本对齐（R496）

## 升级说明

- Windows 用户直接下载新版安装包覆盖安装，或等待应用内自动更新（updater 走 GitHub
  Release `latest.json`，签名公钥已内置校验）。
- 旧版社区脚本（本地粘贴安装的）不受影响，继续可用。
