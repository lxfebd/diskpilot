# DiskPilot v1.0.1 更新日志（2026-11-08）

v1.0.0 后的首个补丁版。面向用户的发布说明（GitHub Release 描述可直接粘贴本文件）。
详细逐轮记录见 [CHANGELOG.md](../../CHANGELOG.md) 的 `[1.0.1]` 段（R504–R543）。

## 亮点

- **11 个官方诊断插件**：大文件/重复文件/临时文件/日志/端口/硬盘健康/浏览器缓存 + 启动项/注册表/服务/计划任务审计三件套（v1.1.0 带 `--json` 结构化输出），全部进「今日体检」
- **待人工确认清单**：体检发现的失效/可疑项入队，支持 Markdown/CSV 导出报告，处置仍走确认窗
- **持久化通知中心**：周报/空间预警/扫描提醒/自动导出入列，侧栏未读角标，历史页可回看
- **健康警示三处一致红标**：硬件主卡温度、趋势图阈值线、SMART 异常盘整行 + 周报异常盘清单
- **工程化**：GitHub Actions 全升 v7、dependabot PR 队列清零、插件下载排行榜、README 徽章区

## 升级提示

- 从 v1.0.0 升级无破坏性变更；内置 updater 会自动提示本版本（latest.json 已切换）。
- 发布链路新增 bundler 工具预下载步骤（R544），对抗 GitHub release-assets 偶发 504。
