# DiskPilot v1.0.0 更新日志（2026-11-08）

首个正式版。面向用户的发布说明（GitHub Release 描述可直接粘贴本文件）。
详细逐轮记录见 [CHANGELOG.md](../../CHANGELOG.md) 的 `[1.0.0]` 段（R381–R521，共 30 轮）。

## 亮点

- **安全确认链全覆盖**：所有写操作（清理执行、工具运行、插件安装/卸载、MCP 写工具、
  agent 写调用）统一走「确认面板 + 一次性 nonce（60 秒 TTL、防重放）」双闸；7→19→20 条
  命令陆续入闸，100% 覆盖，审计日志落盘（详见 [docs/security-model.md](../security-model.md)）。
- **官方插件市场上线**：9 个只读诊断插件（大文件/重复文件/启动项/临时目录/大日志/
  端口/磁盘健康/浏览器缓存/计划任务），全部 Ed25519 双签 + sha256 锚定官方公钥，
  索引仓库 `lxfebd/diskpilot-plugin-index` + CI 结构门禁 + 客户端验签三层防护；
  社区 PR 演练实测：坏结构被 CI 拒、未重签信封被客户端拒（详见
  [docs/plugin-market-index.md](../plugin-market-index.md)、[docs/publish-plugin-guide.md](../publish-plugin-guide.md)）。
- **扫描报告导出**：扫描结果一键导出 Markdown / CSV / JSON（工作区头部按钮，不重新读盘）。
- **空间趋势预测**：总览卡片用最小二乘回归外推「预计某日填满」（R² 置信度，样本少标粗估）。
- **健康管家 P0–P2 闭环**：今日体检横幅汇总红盘/可回收/温度/启动项/硬盘健康/扫描时效/
  插件体检；周报、温度持续偏高与启动项变化通知、按项授权自动进清单——全部只读 + 只通知，
  删除永远走用户确认（详见 [docs/health-butler.md](../health-butler.md)）。
- **质量门禁**：三平台 CI（含 `--self-test` 冒烟）、发布前 19 项一键验收
  （`pnpm check:release`）、cargo audit 白名单、CHANGELOG/文档链接双守卫。

## 升级提示

- 从 0.2.x 升级无破坏性变更；插件市场首次打开会拉取官方索引（需联网），
  安装任何插件前请核对「已验签」标识。
- macOS 版仍为未签名构建，首次打开需右键 → 打开。
