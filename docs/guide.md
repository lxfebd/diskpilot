# DiskPilot 使用说明书

> 适用于：普通用户。当前版本 v0.2.1。
> 下载：[GitHub Releases](https://github.com/lxfebd/diskpilot/releases)

## 1. 安装

### Windows
1. 下载 `DiskPilot_0.2.1_x64-setup.exe`，双击安装
2. 首次启动若被 SmartScreen 拦截：点「更多信息」→「仍要运行」
3. 应用需要管理员权限（NTFS MFT 直读），启动时会自动弹 UAC，点「是」即可

### macOS
下载 `.dmg`（Apple Silicon 选 `aarch64`，Intel 选 `x64`）。**未签名公证**，首次打开需右键 →「打开」。尚未在真机全面验证，问题欢迎提 issue。

### Linux
`.deb` / `.rpm` / `.AppImage` 任选。CI 产物，未在真实机器上系统验证过。

### 自动更新
所有安装包带签名，发新版后应用内会提示升级，无需手动重装。

## 2. 第一次打开

1. **免责声明**：首次进入会弹出一份 10 秒能读完的说明（这个软件会做什么、不会做什么），读完勾选后才能进入
2. **配置 AI（可选）**：右上角 ⚙ → AI 标签，填一个 Key 即可：
   - Anthropic / OpenAI / Gemini：填 API Key（存在你本机，请求直发服务商）
   - Ollama：本地跑模型，完全免费，填服务地址即可
   - 不配 AI 也能用全部扫描与清理功能，只是不能"拖给 AI 问"
3. **语言 / 主题**：⚙ 里可切换中/英文与浅色/深色主题

## 3. 扫描磁盘

- 顶部「一键扫描全部硬盘」扫所有盘；或点单个盘符卡片只扫那个盘
- Windows 整盘通常 2-5 秒（MFT 直读）；其他平台走普通遍历，会慢一些
- 已扫过的盘再点开是**秒开**（直接出上次结果）；盘符卡片上的刷新图标才会强制重扫
- 扫描过程可随时取消

## 4. 看结果

三个视图，顶部标签切换：

| 视图 | 用途 |
|---|---|
| **总览** | 磁盘卡片墙、各盘空间使用趋势曲线、文件分类占用、"建议清理项目"清单（勾选后一键清理） |
| **工作台** | 左：文件夹树（每行带占用条，可展开下钻）· 中：文件详情 / AI 对话 · 右：Studio 清理脚本卡片 |

彩色 treemap（面积 = 占用）在工作台内可切换显示。

## 5. 问 AI："这个文件夹是什么"

1. 在树里找到不认识的大文件夹
2. **把它拖进中间的聊天框**（或右键 → 问 AI）
3. AI 会回答：这是什么、能不能删、删了会丢什么
4. 回答里的建议若涉及删除，仍需你确认后才会执行

隐私说明：发给 AI 的只有目录元数据（路径名、大小、文件数、扩展名占比、少量样本路径），**程序永远不会读取你的文件内容**。

## 6. 清理脚本（Studio）

右侧 Studio 列出应用已在本机检测到的清理脚本（微信、Conda、浏览器缓存、QQ、Discord、IDE、游戏引擎、Teams、Zoom、安全软件等 18 份）。打开卡片 → 看到各 scope 的可释放量 → 勾选 → 清理。

安全边界：

- 每份脚本只清"确定是缓存/可再生"的目录；聊天数据库、收藏、登录态、凭据等列在**红线清单**，代码层面禁止触碰
- 删除默认进**系统回收站**，可恢复
- 高危项目（如微信聊天备份）需要输入"确认"口令的两步确认

## 7. 撤销

底部「最近清理」面板：每一步删除都记录在 `~/.diskpilot/undo.jsonl`，点撤销即从回收站（或隔离区）找回。开了 quarantine 模式的文件会先在 `~/.diskpilot/quarantine/` 存 7 天。

## 8. 工具墙与硬件中心

- **工具墙**：CPU / 内存 / 显卡 / 磁盘 / 烤机 / 游戏 / 外设等 12 分类，单击看详情、双击启动；每个工具有风险徽标，最高危一档永久禁止运行
- **硬件中心**：基准测试（CPU/内存/磁盘/GPU）、压力测试（温度超限自动熔断）、全传感器快照（温度/风扇/电压/功耗）、体检报告
- **AI 可操作分区**：这里列出的工具可被 AI agent 调用；只读工具直接可用，写操作工具必须由你在界面上两步确认

## 9. 给外部 AI agent 接入（MCP）

DiskPilot 自带一个标准 MCP server（stdio）。以 Claude Desktop 为例，在其配置文件中加：

```json
{
  "mcpServers": {
    "diskpilot": {
      "command": "<DiskPilot 安装目录>/agent-server[.exe]"
    }
  }
}
```

接入后 AI 获得 75 个工具：64 个只读（磁盘健康 / SMART / 大文件 / 重复文件 / 进程 / 服务 / 传感器 / 网络 / 事件日志 / 回收站 / 软件清单 / Steam 盘点……）+ 11 个写操作（回收文件 / 结束进程 / 卸载软件 / 压测……）。**写操作全部要求 `confirmed` 参数**，外部 AI 无法绕过用户确认改变系统状态。

## 10. 常见问题

| 问题 | 解答 |
|---|---|
| 为什么要点 UAC？ | MFT 直读需要管理员权限；拒绝提权会自动降级为普通遍历（慢，但可用） |
| 扫描数据会上传吗？ | 不会。一切都在本机 `~/.diskpilot/`，无云端 |
| 删错了怎么办？ | 回收站 + 「最近清理」撤销 + 可选隔离区，三层找回 |
| 支持哪些系统？ | Windows 10/11 完整支持；macOS / Linux 可编译运行，验证尚不充分 |
| AI 要花多少钱？ | BYOK 自选；用本地 Ollama 零成本 |
